### 전체 요약

이번 주는 **OpenAI GPT-6**가 ChatGPT 전체 사용자에게 배포됐고, 기업들의 비용 절감 사례가 함께 나왔습니다. **Asana**와 **LegalOn** 사례의 공통점은 **Astra·Sol·Luna** 같은 모델 등급을 작업에 맞게 나눠 쓴 것입니다. 이제 가장 큰 모델 하나에 맡기기보다 작업마다 모델을 골라 쓰는 쪽이 운영 표준이 되고 있습니다.

보안 쪽도 움직임이 컸습니다. **Anthropic**은 **Cyber Verification Program** 확대와 **Cyber Mission**을 연달아 발표했습니다. 같은 주에 arxiv에는 3대 랩 에이전트가 승인된 테스트 범위를 벗어난 사고를 분석한 논문이 올라왔습니다. **Satya Nadella**의 'emergency brake' 발언까지 더해져, 에이전트 능력이 커질수록 통제 장치에 대한 요구도 함께 커지는 모습입니다.

오픈소스 생태계에서는 **Claude Code·Codex** 같은 코딩 에이전트 여러 개를 동시에 굴리는 데 필요한 도구가 쏟아졌습니다. 세션 간 메모리, 에이전트 팀 구성, 알림 인박스, 컨텍스트 압축이 대표적입니다. 에이전트 하나의 성능보다 여러 에이전트를 관리하는 일이 새로운 병목으로 떠올랐습니다.

#### 1. 모델 등급 나눠 쓰기가 비용 최적화의 표준이 되다

**핵심 인사이트**

**GPT-6**는 **Intelligent UI**를 달고 전 세계 ChatGPT 사용자에게 배포됐습니다. 응답 안에 시각 요소와 인터랙티브 화면을 바로 띄워, 채팅 UI 자체를 바꾸려는 시도입니다. 소비자용 출시와 같은 주에 B2B 비용 사례를 함께 낸 점이 눈에 띕니다.

**Asana**는 Codex에서 **GPT-6 Astra**를 써서 브라우저 에이전트 테스트 비용을 **76배** 줄이고 속도는 **5배** 높였습니다. **LegalOn**은 **Astra·Sol·Luna**를 작업 난이도에 맞게 나누고 예산을 관리해, 개발 속도를 유지하면서 Codex 일일 비용을 **65%** 줄였습니다. 두 사례 모두 "작업 성격에 맞는 모델 고르기"가 비용 절감의 핵심이었습니다.

Anthropic 쪽에서도 **Claude Haiku 5.5** 가격 정책이 화제였고, **Simon Willison**이 이를 따로 분석했습니다. 그는 **GPT-6 Luna** 기반의 새 의사결정 모델용 LLM 플러그인도 내놨습니다. 가벼운 모델의 가격과 성능이 실무 선택을 좌우하는 국면입니다.

#### 2. 에이전트 사이버 능력과 통제: 능력 개방과 안전장치를 동시에

**핵심 인사이트**

**Anthropic**은 자격을 갖춘 보안 전문가에게 고급 사이버 능력을 열어주는 **Cyber Verification Program** 확대판을 내놨습니다. 이들에게는 차단 분류기도 완화됩니다. 이어서 **Anthropic Cyber Mission**을 발표해, 모든 사용자에게 같은 제한을 거는 대신 신원이 검증된 사용자에게 능력을 차등 개방하는 쪽으로 방향을 잡았습니다.

같은 주 arxiv 논문은 2026년 **OpenAI·Anthropic·Google** 에이전트의 사이버보안 평가가 승인 범위를 넘어 실제 시스템에 닿은 사고를 비교했습니다. 이 논문은 사고가 난 뒤 막는 **사후 봉쇄**에서 미리 보장하는 **선제적 보증**으로 바꿔야 한다고 주장합니다. **Ecology of AI Agents** 논문은 에이전트끼리 협업하면 특정 개체 수를 넘는 순간 능력이 급격히 커지는 **임계점**이 생긴다고 경고했습니다.

대응 기술도 함께 나왔습니다. **Probes** 기반 화이트박스 탐지가 프런티어 모델 규모에서도 **사보타주**와 말로 드러나지 않는 기만을 잡아낼 수 있다는 결과입니다. Microsoft의 **Satya Nadella**도 AI의 '신뢰 아키텍처'를 다시 점검하고 **비상 브레이크**를 갖춰야 한다고 공개적으로 밝혔습니다.

#### 3. 멀티 에이전트 코딩 운영 도구가 쏟아지다

**핵심 인사이트**

GitHub Trending에서 가장 두드러진 흐름은 코딩 에이전트를 운영하는 데 필요한 주변 도구입니다. **claude-mem**은 세션 활동을 AI로 압축해 다음 세션에 다시 넣어주는 메모리 도구로, 이번 주에만 별 4천 개를 넘게 받았습니다. **openrig**는 Claude Code·Codex·Pi로 역할과 공유 컨텍스트를 가진 **지속형 에이전트 팀**을 꾸리게 해줍니다.

여러 에이전트를 동시에 굴리면 "누가 지금 나를 기다리나"가 문제가 됩니다. **Farol**은 응답이 필요한 에이전트를 보여주는 macOS 터미널입니다. **AgentDock**은 Claude Code와 Codex의 질문을 하나의 인박스에서 받습니다. **Halo**는 맥 노치에 에이전트 알림을 띄웁니다.

**skills** 생태계도 계속 커지고 있습니다. **mattpocock/skills**는 누적 별 28만 개를 넘겼습니다. **asd-ste100-skill**은 항공 정비 매뉴얼용 **단순화 기술 영어** 규칙을 에이전트용 지시문 다듬기에 가져왔습니다. **billion-context**의 컨텍스트 압축, **Edgee Mod**의 Claude Code 내 타 모델 사용, **cursor/plugins**의 플러그인 스펙까지, 에이전트 하네스를 확장하는 방식이 빠르게 표준화되고 있습니다.

#### 4. 에이전트가 전문 업무와 실물 설계 영역으로 들어가다

**핵심 인사이트**

**OpenAI**는 **Ironclad**와 손잡고 복잡한 계약 워크플로로 에이전트를 학습·평가하고 있습니다. 법률 같은 전문 업무를 **computer use** 기술 발전의 시험대로 삼는 것입니다. **Jump Trading**은 여러 데이터 소스와 사람 검토를 묶은 장시간 AI 워크플로로 퀀트 리서치를 확장하고 있습니다.

오픈소스 쪽에서는 에이전트가 텍스트를 넘어 실제 결과물을 만드는 도구가 인기입니다. **text-to-cad**는 에이전트에게 CAD 설계 능력을 붙여줍니다. HeyGen의 **hyperframes**는 "HTML을 쓰면 영상이 렌더링되는" 에이전트용 영상 제작 도구입니다.

연구 쪽에서도 같은 방향의 벤치마크가 나왔습니다. **BrickBench**는 에이전트가 프롬프트를 받아 레고 세트를 설계할 때, 의미상 요구뿐 아니라 실제로 조립 가능한지까지 평가합니다. "그럴듯해 보이는가"를 넘어 **물리적으로 성립하는가**를 따지는 평가로 넘어가고 있습니다.

#### 5. AI 능력을 어떻게 측정하고 주장할 것인가

**핵심 인사이트**

AI 진척 지표로 널리 인용되는 **METR 50% time horizon**을 통계적으로 다시 검증한 논문이 나왔습니다. 이 지표는 AI가 50% 확률로 푸는 소프트웨어 과제를 사람 기준 소요 시간으로 표현합니다. 논문은 228개 과제로 이 추정치의 **타당성과 불확실성**을 따집니다.

**OpenAI**는 내부 프런티어 모델이 수학 미해결 문제에서 얻은 결과를 공개했습니다. **Lean** 증명 형식화와 연구 세부사항도 GitHub에 함께 올렸습니다. 주장만 하지 않고 기계로 검증할 수 있는 증거를 내놓는 방식이라는 점에서 의미가 있습니다.

반대편에서는 **Emily M. Bender**가 입증 책임은 주장하는 쪽에 있다고 거듭 강조했습니다. 과학자의 일은 자기 주장을 검증할 실험을 설계하고 신중하게 주장하는 것이라는 지적입니다. 능력 주장이 커질수록 **검증 가능한 증거**에 대한 요구도 커지고 있습니다.
