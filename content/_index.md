### 전체 요약

이번 주에는 **Anthropic**과 **OpenAI**가 같은 날 새 프런티어 모델을 내놓았습니다. 긴 코딩 세션을 겨냥한 **Claude Opus 5.5**와, 성능과 비용의 균형을 달리한 **GPT-6 Sol·Luna**입니다. 모델 경쟁의 기준이 벤치마크 점수보다 **실제 업무에 드는 비용과 사용할 수 있는 컨텍스트 길이**로 옮겨가고 있습니다.

모델 바깥에서는 **에이전트를 유통하는 플랫폼**을 두고 경쟁이 벌어졌습니다. Anthropic은 **Claude Marketplace**와 플러그인 빌드 가이드를 공개했습니다. GitHub Trending 상위권도 에이전트 관리 도구, 하네스(에이전트 실행 환경), 메모리 저장소가 차지했습니다.

한편 AI는 정치와 외교의 무대에서도 다뤄졌습니다. **Sam Altman**은 유엔 안보리에서 발언했고, **Dario Amodei**는 트럼프 대통령과 처음으로 단독 만찬을 가졌습니다. **워터마킹**, AI 콘텐츠 판별, 정신건강 안전성 벤치마크처럼 **신뢰를 다루는 인프라**에 대한 논의도 함께 늘었습니다.

#### 1. Opus 5.5 vs GPT-6 Sol·Luna — 경쟁 기준이 "긴 컨텍스트"와 "절반 가격"으로

**핵심 인사이트**

**Claude Opus 5.5**는 코딩 세션이 길어지고 컨텍스트를 더 많이 쓰는 흐름에 맞춰 설계됐다고 소개됐습니다. OpenAI의 **GPT-6 Sol·Luna**는 "프런티어급 지능을 절반 가격에"라는 메시지를 내세웠습니다. 한쪽은 긴 작업을 버티는 능력을, 다른 쪽은 가격 대비 성능을 앞세운 셈입니다.

OpenAI는 같은 날 **GPT-6 프롬프트 캐싱 개선**도 발표했습니다. 캐시 적중률 향상, 명시적 캐시 지점(breakpoint), 진단 도구를 추가해 지연 시간과 비용을 줄이는 내용입니다. 모델 성능만큼이나 **추론 비용을 얼마나 낮출 수 있느냐**가 경쟁 요소가 됐다는 뜻입니다.

**GPT-6 Astra** 도입 사례도 여러 건 공개됐습니다. **Harvey**는 법률 문서 초안 품질을, **invideo**는 색보정 품질(3배 향상)을, **Airbnb**는 엔지니어링 생산성을 성과로 들었습니다. **Simon Willison**은 세 모델을 추론 수준별로 비교한 "펠리컨 그리드"로 이 모델 전쟁의 체감 차이를 기록했습니다.

#### 2. 에이전트 유통 플랫폼 경쟁 — 마켓플레이스·플러그인·하네스

**핵심 인사이트**

Anthropic이 **Claude Marketplace**를 열었습니다. 파트너사의 플러그인, 에이전트, 서비스를 한곳에서 찾아 쓰는 구조입니다. 여기에 **플러그인 빌드 가이드**와 **Claude Tag의 개인 커넥터 지원**을 더하면서, 모델을 파는 회사에서 **생태계를 운영하는 플랫폼**으로 옮겨가고 있습니다.

오픈소스 쪽도 같은 방향입니다. [paperclip](https://github.com/paperclipai/paperclip)(업무용 에이전트 관리)과 [orca](https://github.com/stablyai/orca)(병렬 에이전트용 개발 환경)가 각각 주간 6~7천 스타를 받았습니다. 누적 26만 스타의 [ECC](https://github.com/affaan-m/ECC)는 여러 코딩 에이전트에 두루 쓰는 **하네스 최적화 도구**로 자리 잡았습니다.

**Zerg Router**(Codex에서 DeepSeek 실행)와 **Harness Router** 같은 **라우팅 도구**도 나타났습니다. 특정 벤더에 묶이지 않고 에이전트와 모델을 섞어 쓰려는 수요가 커지고 있음을 보여줍니다.

#### 3. 에이전트 메모리와 지식 저장소가 인기 상위권에

**핵심 인사이트**

이번 주 GitHub Trending에서 가장 빠르게 성장한 저장소는 [hindsight](https://github.com/vectorize-io/hindsight)였습니다. 사용할수록 학습하는 **에이전트 메모리**를 내세우며 주간 1.1만 스타를 받았습니다. 에이전트가 세션이 바뀌어도 맥락을 잃지 않게 하는 문제가 개발자들의 가장 큰 관심사라는 신호입니다.

**Tencent WeKnora**는 원문 문서를 RAG, 추론 에이전트, 스스로 갱신되는 위키로 한 번에 바꿔 주는 지식 플랫폼입니다. Product Hunt의 **Hemory**는 에이전트용 검색 가능한 메모리를 제공합니다. 메모리 계층이 별도 제품군으로 떨어져 나오고 있습니다.

다만 문서를 많이 주는 것이 곧 해답은 아니라는 연구도 나왔습니다. arxiv의 **Compact Documentation for Coding Agents** 논문은 코딩 에이전트용 문서를 최적화하는 도구를 만들었지만, 그 효과가 **다른 환경으로 전이되지 않았다**고 보고합니다.
