**왜 중요한가**

GitHub MCP 하나로 50K 토큰이 소모되고 100K 이상에서 Lost in the Middle로 성능이 급락한다는 실측과, 게이트웨이 레이어에서 Semantic Tool Discovery로 의도에 맞는 도구만 사전 필터링하는 패턴을 제시합니다. DCSAI의 자체 MCP host server와 Team Agent의 dcsai KG MCP 직연결 모두를 관통하는 컨텍스트 세금 문제를 정조준합니다.

**접목 →** DCSAI MCP host server에 Semantic Tool Discovery 레이어를 추가해 tool 목록을 agent loop 진입 전 의도 기반으로 사전 필터링하고, Team Agent의 `discovery-core-agent`/`platform-core-agent`가 dcsai KG MCP에 직접 등록될 때 BrandScopeInterceptor와 결합해 브랜드별로 노출되는 도구 수를 제한하는 구조로 확장할 수 있습니다.
