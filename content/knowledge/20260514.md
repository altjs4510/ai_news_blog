**왜 중요한가**

코딩 에이전트가 실제 OS에서 안전하게 동작하기 위한 격리·신뢰 인프라를 정조준하는 OpenAI의 공식 엔지니어링 글로, agent loop가 호스트 환경에서 tool use를 수행할 때 발생하는 권한 경계·파일시스템 접근 제어 문제를 다룹니다. DCSAI의 MCP host server가 OAuth·세션·tool 실행을 자체 구현하는 결, 그리고 `dcs-ai-cli`·`ff-claude-manager`처럼 로컬 실행 권한을 가지는 구성요소들이 마주칠 샌드박싱 설계와 정확히 같은 결을 건드립니다.

**접목 →** DCSAI의 MCP host server에서 tool 실행 단계에 적용 — Codex Windows 샌드박스가 채택한 파일시스템·네트워크 격리 전략을 참고해 dcsai KG MCP가 외부 클라이언트(Claude Code plugin, `ff-claude-manager` Tauri tray)에서 호출될 때의 권한 경계와 HITL 승인 분기를 강화하는 설계 레퍼런스로 활용 가능합니다.
