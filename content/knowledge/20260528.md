**왜 중요한가**

Codex를 단순 코드 생성기가 아니라 '에이전트가 자기 코드를 수정·개선하는 self-improving 루프'로 운영한 실제 엔터프라이즈 사례로, agent loop와 HITL 분기에서 모델이 산출한 코드의 silent bug를 어떻게 검증·롤백하는지에 대한 구체적 패턴을 제시합니다. DCSAI의 Anthropic SDK 직통합 agent loop · HITL 결과 Team Agent의 Activity Log/Observer 피드백루프(L1) 결을 정조준합니다.

**접목 →** DCSAI agent loop의 HITL 분기에 'self-improving review 단계'를 도입할 때 — 즉 에이전트가 생성한 tool use 결과/코드를 다음 턴에서 스스로 점검·수정하는 루프 설계에 직접 차용 가능. Team Agent에서는 `discovery-core-agent`의 Activity Log → Observer → UI refresh 루프에 '에이전트가 자기 산출물의 유효성을 재평가'하는 L1 피드백 단계로 매핑할 수 있습니다.
