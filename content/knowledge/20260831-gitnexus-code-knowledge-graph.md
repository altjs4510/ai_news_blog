  <h2 class="ai-post-title">GitNexus — 코드베이스를 지식그래프로 바꿔 에이전트에게 쥐어주기</h2>
</header>

코딩 에이전트(Claude Code, Cursor, Codex 등)의 가장 흔한 실패 패턴 중 하나는 "부분만 보고 고친다"는 것이다. `UserService.validate()`를 수정했는데 실제로 그 반환값에 의존하는 함수가 47개 있다는 걸 모른 채 편집이 끝나버리는 식이다. [GitNexus](https://github.com/abhigyanpatwari/GitNexus)는 이 문제를 "에이전트에게 코드베이스 전체의 관계 구조를 미리 계산해서 쥐어주는" 방식으로 풀려는 프로젝트다(코드는 공개돼 있지만 라이선스는 완전한 오픈소스가 아니다 — 아래 참고). 2025년 8월 공개된 이후 1년 만에 스타 4만 6천 개를 넘겼고, 어제(8/30)도 커밋이 올라올 정도로 활발히 관리되고 있다.

## 문제의식: Graph RAG로는 부족하다

코드베이스에 대해 질문하면 LLM에게 그래프 엣지를 던져주고 알아서 탐색하게 하는 게 기존 Graph RAG 접근이다. "UserService에 의존하는 게 뭐야?"라는 질문 하나에 호출자 찾기 → 어떤 파일인지 → 테스트 제외하고 필터링 → 위험도 판단까지 쿼리를 4번 이상 왕복해야 답이 나온다.

GitNexus는 반대로 접근한다. 인덱싱 시점에 클러스터링·트레이싱·스코어링을 전부 미리 계산해두고, MCP 툴 하나를 호출하면 "호출자 8개, 클러스터 3개, 전부 신뢰도 90% 이상"처럼 완성된 답을 한 번에 돌려준다. 저자들은 이걸 "선계산된 관계형 인텔리전스(Precomputed Relational Intelligence)"라 부르며, 신뢰성(에이전트가 맥락을 놓칠 수 없음)·토큰 효율(왕복 쿼리 불필요)·모델 민주화(작은 모델도 툴이 무거운 일을 대신 해주니 잘 작동)라는 세 가지 효과를 내세운다.

## 어떻게 쓰나

두 가지 사용 방식이 있다.

- **CLI + MCP(권장)**: `npx gitnexus analyze` 한 번으로 레포를 인덱싱하고, `npx gitnexus setup`으로 Claude Code·Cursor·Codex·Antigravity·Windsurf 등을 자동 감지해 MCP 연결까지 끝낸다. 이 과정에서 `AGENTS.md`/`CLAUDE.md` 컨텍스트 파일도 자동 생성된다. 파싱은 tree-sitter 네이티브 바인딩을 쓰고, 저장은 자체 그래프 DB(LadybugDB)를 로컬에 둔다 — 네트워크 전송 없이 전부 로컬에서 처리된다는 게 프라이버시 측면의 셀링포인트.
- **웹 UI**([gitnexus.vercel.app](https://gitnexus.vercel.app)): 설치 없이 브라우저에서 레포를 드롭하면 인터랙티브 지식그래프 + 채팅형 Graph RAG 에이전트를 바로 써볼 수 있다. 다만 tree-sitter WASM으로 파싱하고 브라우저 메모리 안에서만 도는 구조라 5천 파일 안팎이 한계(백엔드 모드로 우회 가능).

## 에이전트가 받는 도구들

MCP 툴이 17개(레포별 15 + 그룹 2)나 되는데, 눈에 띄는 것만 추리면:

- `impact` — 특정 심볼을 고치면 어디까지 영향이 퍼지는지 블라스트 반경 분석(깊이별 그룹핑 + 신뢰도 포함)
- `detect_changes` — git diff를 그래프에 매핑해 "이 변경이 건드리는 실행 흐름"을 바로 알려줌
- `trace` — 두 심볼 사이 최단 호출 경로 추적
- `rename` — 여러 파일에 걸친 이름 변경을 그래프+텍스트 검색으로 한 번에 조율
- `cypher` — 그래프에 직접 Cypher 쿼리도 가능

여기에 얹혀서 `.claude/skills/`에 자동 설치되는 스킬 세트(탐색·디버깅·영향분석·리팩토링 등)와, `/gitnexus-plan → /gitnexus-work → /gitnexus-review` 로 이어지는 슬래시 커맨드 파이프라인(계획 → 사람 승인 게이트 → 그래프 기반 원자적 커밋 실행 → PR 리뷰까지)이 딸려온다. `/gitnexus-lfg` 하나로 이 전체 파이프라인을 한 번에 돌릴 수도 있다.

에디터 지원은 Claude Code와 Codex가 가장 깊다 — MCP 툴 + 스킬뿐 아니라, 도구 호출 전후로 그래프 컨텍스트를 자동 주입하고 커밋 후 인덱스가 낡았는지 감지해 재인덱싱을 권하는 훅까지 붙는다.

## 참고할 점

라이선스는 PolyForm Noncommercial — 완전한 오픈소스라기보다 "무료지만 상업적 이용은 별도"에 가깝다. 실제로 엔터프라이즈용 SaaS/셀프호스트 버전을 만든 회사(Akon Labs)가 뒤에 있다. README에는 "GitNexus 이름을 붙인 암호화폐/토큰은 전부 무관하다"는 경고도 큼직하게 박혀 있는데, 이 정도 스타 수를 단기간에 모은 프로젝트가 스캠 사칭 표적이 된다는 걸 보여주는 방증이기도 하다.

DeepWiki류 "코드 이해 도구"들과 스스로를 구분 짓는 표현이 인상적이다 — "DeepWiki가 코드를 *이해*하게 도와준다면, GitNexus는 코드를 *분석*하게 해준다. 단순 설명이 아니라 모든 관계를 그래프로 추적한다."
