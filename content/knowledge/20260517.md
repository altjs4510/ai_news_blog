**왜 중요한가**

117,000개 MCP 도구 환경에서 컨텍스트 윈도우를 늘리지 않고 Lazy Discovery 패턴으로 Gemma 4 E4B(로컬 4B)가 Claude Sonnet 4.6과 거의 동일한 도구 호출 효율(17 vs 19)을 달성한 실증 사례로, MCP host·client 설계의 가장 큰 병목인 'tool list 폭주로 인한 컨텍스트 세금'을 정조준합니다. DCSAI의 자체 구현 MCP host server와 Team Agent의 dcsai KG MCP 직연결 모두에서 핵심 결입니다.

**접목 →** DCSAI MCP host server에 Lazy Discovery 레이어를 도입해 tool 메타데이터를 사전 임베딩 인덱스로 두고 agent loop 진입 시 의도 기반 top-k만 Anthropic SDK에 노출하면, HTTP chunked streaming 한 턴당 토큰을 크게 줄일 수 있습니다. Team Agent도 `platform-core-agent`가 다수 브랜드 MCP를 동시 등록하는 구조라 동일 패턴이 곧장 필요합니다.
