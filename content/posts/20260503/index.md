## AI 에이전트 실전 운영 인사이트

- 🔩 '에이전트 구축의 80%는 배관 작업' — 실제 로직(~200줄)보다 재시도 처리, 손상 입력 핸들링, 모니터링, API 파싱 업데이트가 훨씬 더 많은 시간 소요. 기술보다 운영 역량이 핵심
- 💰 컨텍스트 누적 비용 폭발 주의 — Claude API는 매 호출마다 전체 대화 이력 전송. 루프 46턴 = 800K 토큰. 프롬프트 캐시 TTL ~5분으로 단축되어 30분 간격 자동화는 매번 전체 재캐시 비용 발생 → 하룻밤 $6,000 사례 실재
- 🛠️ 비용 절감 실용 팁 — 무인 자동화엔 Opus 대신 Sonnet 사용(~5배 절감), 루프에 반드시 중지 조건 명시, 5분 이상 간격 작업은 새 세션 시작이 유리, 프롬프트에서 인사말·사과 제거로 토큰 최대 70% 절감 가능
- 🧩 스킬(Skills)이 정적 MCP 도구의 다음 단계 — 수십 개 MCP 도구를 한꺼번에 로드하면 토큰 낭비 심각. 스킬은 런타임에 필요한 것만 동적 발견·실행하는 방식으로 컨텍스트 효율 극대화
